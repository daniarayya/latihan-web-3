Mengapa HTML Penting

HTML penting karena menjadi kerangka utama dari sebuah halaman web. Saat membuka sebuah website, informasi seperti judul artikel, menu, tombol, gambar, dan formulir pada dasarnya disusun menggunakan elemen HTML. Karena itu, memahami HTML membantu kita mengetahui bagaimana sebuah halaman web dibangun sebelum tampilannya dipercantik dengan CSS.

Bagi pemula, HTML juga merupakan tempat yang tepat untuk melatih cara berpikir terstruktur. Misalnya, kita belajar menentukan mana yang seharusnya menjadi judul utama, mana yang termasuk isi artikel, dan mana yang menjadi navigasi. Kebiasaan menyusun struktur dengan benar sejak awal akan memudahkan saat membuat website yang lebih besar.

Tips Pertama

  1. Buat halaman kecil terlebih dahulu. Jangan langsung membuat website yang memiliki banyak halaman. Mulailah dari halaman profil, jadwal kuliah, atau daftar kegiatan sehari-hari.
  2. Tulis struktur HTML tanpa melihat contoh setelah latihan. Setelah mempelajari struktur dasar HTML, coba tutup materi dan tulis kembali sendiri. Cara ini membantu mengetahui bagian mana yang benar-benar sudah dipahami.
  3. Perhatikan pasangan tag pembuka dan penutup. Saat membuat beberapa elemen bersarang, biasakan memeriksa apakah tag ditutup sesuai urutan pembukaannya.
  4. Gunakan nama file yang mudah dipahami. Contohnya gunakan nama seperti profil.html, kontak.html, atau tips.html daripada nama file seperti coba1.html.
  5. Biasakan membaca hasil di browser setiap selesai menambah bagian. Jangan menunggu kode selesai seluruhnya. Dengan mengecek sedikit demi sedikit, kesalahan lebih mudah ditemukan.

Kesalahan Umum

  • Menulis Semua Judul dengan h1

    Beberapa pemula menggunakan tag h1 untuk semua tulisan yang ingin dibuat besar. Padahal heading memiliki tingkatan. Sebuah halaman biasanya memiliki satu judul utama dengan h1, kemudian bagian di bawahnya dapat menggunakan h2 atau h3 sesuai struktur isi halaman.

  • Menggunakan Enter untuk Membuat Jarak

    Menekan Enter berkali-kali di dalam kode HTML tidak selalu menghasilkan jarak seperti yang diharapkan di halaman web. HTML digunakan untuk menyusun isi, sedangkan pengaturan jarak dan tampilan sebaiknya dilakukan menggunakan CSS.

  • Memberi Nama Id yang Tidak Sesuai Tujuan

    Id sebaiknya menggunakan nama yang menjelaskan bagian tersebut. Misalnya, gunakan id="sumber" untuk bagian sumber belajar agar mudah dipahami dan dapat digunakan sebagai tujuan dari anchor link pada navigasi.

  • Lupa Memberikan Alt pada Gambar

    Atribut alt penting karena memberikan deskripsi mengenai isi gambar. Deskripsi tersebut dapat membantu pengguna yang menggunakan pembaca layar dan juga menjadi informasi ketika gambar tidak berhasil dimuat.
